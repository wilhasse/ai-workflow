# Poteto Mode Attribution

This Codex skill is adapted from `pstack` Poteto Mode by Lauren Tan:

https://github.com/cursor/plugins/tree/main/pstack

The source snapshot was pstack version 0.14.3 at commit `bdf7aa355337897f167153e05069aca505dae17c`. The original work is available under the MIT License reproduced in `LICENSE`.

This adaptation converts Cursor-specific invocation, agent, model-routing, and tool assumptions to a repository-scoped Codex skill. It condenses the original supporting skills and playbooks into progressively loaded references and changes invocation to `$poteto-mode`. The adaptation is not endorsed by the original author.
